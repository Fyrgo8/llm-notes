## 使用方式

- 直接在 GitHub 浏览 Markdown 与 PDF
- 使用 Obsidian 打开 `论文阅读笔记/`，获得完整的双链与图谱体验
- 配图与 PDF 都是仓库内文件，不依赖外部图床
- 大体积 PDF 建议直接下载：`State-of-AI-Report-2026.pdf` 有 38.9 MB，网页内嵌预览可能加载缓慢
